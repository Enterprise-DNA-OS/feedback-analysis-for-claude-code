# Assign a feedback improvement

Use an agreed action, named owner and due date. Keep the evidence link through its theme and dataset.

```bash
npm run feedback -- add-action --dataset="Harbour customer survey" --theme="Delivery reliability" --reference=A-003 --title="Review carrier cutoffs" --owner="Aroha" --due=2026-10-30 --actor="Operator"
```

Replace example values with the authorised records. For machine-readable output append --json. Resolve ambiguous names by showing the candidates and selecting the intended identifier. Never guess. Present the result in plain language with its dataset and sample size where relevant.
